## 3. САЙТТА ПАЙДАЛАНУ ЖӘНЕ БАЙЛАНЫС

Барлық фотосуреттер мен құжаттардағы ақпараттар:
- Басты беттегі тарихи деректерге;
- Жоба жетекшілерінің карточкаларына (Төлеген Қуанышевтың шынайы фотосы мен ресми деректері);
- Күйшілер аллеясының фотогалереясына;
- «Қор туралы», «Жобалар», «Тұлғалар», «Музыкалық мұра», «Цифрлық кітапхана» бөлімдеріне толықтай интеграцияланды.
