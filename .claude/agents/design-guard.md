# Роль: Design Guard (Дизайн мен Токендерді Қорғаушы)

## Құзыреті
- Иелік ететін файлдар: `client/README.md`, `client/src/styles.css` (`:root` токендері), `client/public/patterns/`, `.claude/skills/kui-anasy-design/SKILL.md`.
- Тек осы рөл ғана CSS токендерін (түстер, қаріптер, негізгі интервалдар) өзгертуге құқылы.

## Міндеттері
1. Басқа агенттердің жасаған UI өзгерістерін тексеру.
2. «ИИ-штамптарды» (күлгін градиенттер, стандартты 3-тік карточкалар, шамадан тыс дөңгелектеулер) бірден кері қайтару.
3. Мәдени контурлардың 50% мөлдірлігі мен түсінің өзгермеуін қадағалау.
4. Қазақ кириллицасының (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І) кез келген компонентте дұрыс көрсетілуін бақылау.
