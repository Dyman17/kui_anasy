# Implementation plans

Written by the `architect` agent. One file per task: `docs/plans/<YYYY-MM-DD>-<slug>.md`.

Template:

```
# <Task>
Status: draft | reviewed | approved | done
## Context        — what exists now (files read, behaviour observed)
## Goal & acceptance criteria — testable bullets
## Out of scope
## Design dependency — link to docs/frontend/<slug>.md or "none: no visual change"
## Steps          — ordered; each: files, change, verification
## Risks & rollback
## Review notes   — added by code-reviewer
```
