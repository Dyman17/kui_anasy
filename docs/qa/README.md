# QA reports

Written by the `qa-engineer` agent (skill: `visual-testing`). One file per verification run: `docs/qa/<YYYY-MM-DD>-<slug>.md`.

Each report states: what was tested, environment (browser tool or "not verified in a browser"), the viewport × theme matrix actually covered, results per check (pass / fail / not run), evidence (screenshot description, console output, page read), and open defects ranked P0–P3.

Older phase reports live in the repo root (`PHASE_2_QA.md`, `PHASE_3_QA.md`) and are left there.
